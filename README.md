# Shisa feedback

This is the public place to report bugs and request features for
[Shisa](https://shisa.dev), the macOS menu-bar security app.

- **Found a bug?** [Open a bug report](../../issues/new?template=bug_report.yml).
- **Have an idea?** [Request a feature](../../issues/new?template=feature_request.yml).
- **Found a security issue?** Don't open an issue. Report it privately through
  [Security → Report a vulnerability](../../security/advisories/new) or by email
  to huybuidac@gmail.com.

Search the [existing issues](../../issues) first, and add a 👍 to one that
matches yours instead of opening a duplicate.

## Before you post

Shisa checks files, folders and settings on your Mac, so reports can easily
include private details. Before you submit, remove:

- file names, folder paths and your user name;
- wallet addresses, recovery phrases, tokens, passwords and keys;
- screenshots that show any of the above.

## Source code

Shisa's source code is not in this repository. Shisa is source-available, not
open source: Shisa Pro includes read access to the source under the Shisa
Source License 1.0.
